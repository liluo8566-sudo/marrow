description: Cortex — send a direction to the tg shell.
---

⚙️ [CMD ct-direction] $ARGUMENTS is the direction text. Run `mw shell-direct $ARGUMENTS --shell tg` via Bash and report its one-line output (`queued for shell=tg kicked=<true|false>`). `kicked=False` means the shell host is down — the text still waits in the ledger. Do not write the shell's ledger file yourself.
